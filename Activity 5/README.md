# Activity 5 – Exploring and Improving AI Prompts

## Activity Description

This activity focused on exploring how prompt engineering can improve the quality of responses generated by artificial intelligence tools. Using ChatGPT, I created an original prompt, refined it with the help of another leading language model, and compared the outputs to identify the effects of providing clearer and more specific instructions.

## What I Did

- Created an original prompt using ChatGPT.
- Used another large language model to improve the original prompt.
- Applied the refined prompt to generate a second output.
- Compared the two outputs based on clarity, detail, accuracy, and usefulness.
- Examined how specific instructions and context influenced the generated responses.

## Learning Reflection

This activity helped me understand the importance of prompt engineering in obtaining relevant and useful AI-generated responses. I learned that providing clear instructions, context, and specific expectations can significantly improve an AI tool's output. One challenge was identifying how to make the original prompt more effective; I addressed this by refining its instructions and specifying the expected content. In the future, I can apply these skills when using AI tools for academic research, writing, and other tasks that require accurate and organized information.

## Skills Developed

- AI literacy and responsible AI use
- Prompt engineering
- Critical thinking and output evaluation
- Comparative analysis
- Effective communication with AI tools
