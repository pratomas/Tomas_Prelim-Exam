# Activity 2: Color Palette and Typography

## Activity Description

This activity focused on exploring the importance of color selection and typography in visual design. It involved creating a coordinated color palette and selecting appropriate typefaces to establish a consistent visual identity.

The activity emphasized how colors and fonts influence the mood, readability, visual hierarchy, and overall appearance of a design.

## What Have I Learned?

Through this activity, I learned that color and typography are essential elements of effective visual communication. I gained a better understanding of how color combinations can establish a particular mood and how different typefaces can create visual hierarchy and improve readability. One challenge I encountered was selecting colors and fonts that complemented one another while maintaining a balanced and consistent appearance. I addressed this by assigning specific roles to each color and typeface instead of using them randomly. In the future, I can apply these principles when designing presentations, infographics, websites, and other digital materials, while continuing to improve my understanding of visual identity and design consistency.
