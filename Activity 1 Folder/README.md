# Activity 1: Presentation Design Principles

## Activity Description

This activity focused on applying fundamental presentation design principles through the creation of a promotional coffee graphic. The output featured the message **"FREE COFFEE. NO CATCH."** and the supporting tagline **"JUST CAFFEINE AND GOOD VIBES."**

The activity aimed to develop an understanding of how visual elements, typography, color, layout, and information hierarchy can be used to communicate a message effectively and capture the audience's attention.

## What Have I Learned?

Through this activity, I learned that effective visual communication requires more than simply combining attractive images and text. I understood the importance of visual hierarchy, readability, alignment, contrast, and proper placement of elements in creating an organized and engaging design. One challenge I encountered was arranging the text and visual elements without making the promotional material look overcrowded. I addressed this by prioritizing the main message and organizing the supporting information to make the design easier to understand. In the future, I can apply these principles when creating academic presentations, promotional materials, and other digital content, while continuing to improve my creativity and design skills.

## Skills Developed

- Application of basic presentation design principles
- Visual hierarchy and information organization
- Typography and text readability
- Layout and alignment
- Creative visual communication
