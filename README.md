# 🎨 ACTIVITY 01
## Presentation Design Principles

### ☕ Free Coffee Promotional Design

This activity focused on applying presentation and visual design principles to create an engaging promotional material.

The output promotes a **Free Coffee** event at **Arrupe Hall, Booth 7**, using a simple and memorable message:

> **"FREE COFFEE. NO CATCH."**  
> **"JUST CAFFEINE AND GOOD VIBES."**

The design also presents the date, location, and first-come-first-served arrangement.

### 🎯 Design Goal

The goal was to create a promotional material that communicates important information quickly while maintaining a fun, inviting, and visually engaging presentation.

### ✨ Design Elements

- Visual hierarchy
- Readability
- Information placement
- Attention-grabbing statements
- Promotional communication
- Consistent visual presentation
