# Activity 6 – Making a Website

## Activity Description

This activity involved creating a one-page personal website using an AI-powered website-building tool. I used Covey Converge AI to develop a website introducing myself, presenting my educational background, highlighting my academic experiences, and sharing my skills, interests, and aspirations.

## Live Website

[Visit My Personal Website – A Little About Me](https://covey.converge.ai/asset-share/ahsl_dc027uoide5nspmilb8g)

## Website Features

- **Home:** Introduction and personal profile
- **About Me:** Personal background and interests
- **Educational Background:** Academic information
- **Academic Portfolio:** Selected academic experiences and accomplishments
- **Skills and Interests:** Personal abilities and areas of interest
- **Values and Aspirations:** Personal goals and future plans
- **Contact:** Contact information

## Learning Reflection

This activity helped me understand how AI-powered tools can simplify website development and turn ideas into a functional digital platform. I learned how to organize information into clear sections and consider the importance of visual consistency, layout, and user experience. One challenge was ensuring that the website presented information in an organized and visually appealing way; I addressed this by structuring the content and using a coordinated color palette. In the future, I can apply these skills when creating personal portfolios, academic websites, and other digital projects.

## Skills Developed

- AI-assisted website development
- Basic web design concepts
- Content organization
- Visual design and color coordination
- Digital communication and self-presentation
